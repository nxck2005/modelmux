# Progress

## Milestone 0: project scaffold

### Scope

Create a minimal installable Python project and its development tooling. This
milestone does not implement routing or any harness integration.

### Created

- `pyproject.toml` with the package metadata, core dependencies, optional
  service extra, development dependency group, and tool configuration.
- `uv.lock` generated by uv from the project configuration.
- `src/modelmux/__init__.py` with only the package declaration.
- `tests/README.md` reserving the test directory without a meaningless test.
- A short Python CI workflow for Python 3.11.
- Scaffold status and development instructions in `README.md`.

### Verification

- `uv lock` generated `uv.lock` and resolved 27 packages.
- `uv sync --locked --dev` installed the locked development environment.
- `uv lock --check` confirmed the lockfile matches the project configuration.
- `UV_PROJECT_ENVIRONMENT="/tmp/opencode/modelmux-m0-base" uv sync --locked --no-dev --no-editable` installed the base package in a clean temporary environment without the service extra.
- `/tmp/opencode/modelmux-m0-base/bin/python -c 'import importlib.util; import modelmux; assert importlib.util.find_spec("starlette") is None; assert importlib.util.find_spec("uvicorn") is None'` imported `modelmux` successfully and found neither service dependency.
- `uv run ruff format --check src tests` passed.
- `uv run ruff check src tests` passed.
- `uv run mypy` passed.
- `uv run pytest` collected zero tests and reported that no tests ran. This is the expected scaffold state; its no-tests status was not converted to success.

Remote GitHub Actions were not run, so this records local verification only.
